# site

Personal site, static, served by GitHub Pages.

- `index.html` — single page, no build step, no dependencies
- `assets/favicon.svg` — mark used in the header too
- `PROFILE-README.md` — the README for the `Evilmcmc/Evilmcmc` profile repository

## Publishing

The site is plain files: enabling Pages with "Deploy from a branch → main → / (root)"
is enough. Nothing to compile.

After the GitHub account is renamed, this repository becomes `USERNAME.github.io`
and GitHub redirects the old address.
