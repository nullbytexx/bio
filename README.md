# Nyx Byte — site

Source for **https://evilmcmc.github.io/** — one static page, no build step,
no dependencies, no external fonts.

```
index.html          the whole page
assets/favicon.svg  mark used in the header and as the tab icon
```

Publishing: GitHub Pages, deploy from `main`, root folder. Nothing to compile.

The profile readme lives in a separate repository whose name matches the account
name, because that is the only place GitHub renders it on the profile page.
