Engineering

  • Index on disk, not in RAM. Holding 55M records as in-memory sets costs 5–6 GB. Eight bytes per record sorted and memory-mapped costs 430 MB and leaves the resident set almost untouched.
  • Binary protocol instead of JSON. 33 bytes per key in, one byte per key out. A JSON envelope at tens of thousands of keys per second costs more than the lookup itself.
  • Own address decoders. bech32, base58check, checksum verification, 34 µs per address, no external dependency.
  • Two-level verification. The fast index works on a truncated key; a candidate is confirmed with an exact query before anything is reported.

Resilience

  • Process death — Restart=always with no attempt limit, since the default policy gives up after five starts.
  • Network loss while the process is alive — a watchdog restarts the node only when it has zero peers and is idle by CPU, which is what an isolated node looks like.
  • Useless peers — peers holding a slot without delivering are dropped by bytes received over time; seven removed, throughput up 21 Mbit in the same minute.
  • Reboot — everything returns on its own, and each start is logged with height, rewind and peers.
  • systemd sandbox — ProtectSystem=strict kept intact; the two files a hook needs are opened explicitly instead of switching the sandbox off.
